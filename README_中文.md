# SafeCam Final UI

这是稳定最终版源码包，重点是稳定、界面好看、远程设置方便。

## 功能

- 本机漂亮 UI
- 浏览器漂亮 UI
- 实时监控
- 远程设置页面
- 循环抓拍记录
- 网页回放
- 自动清理旧记录
- 夜间低光增强
- 黑白增强
- 手电筒补光远程开关
- 开机自启开关
- 最大空间可设到 100GB

## 默认参数

- PIN：123456
- 端口：8080
- 循环记录：开启
- 记录间隔：1 秒
- 保留：72 小时
- 空间上限：30000 MB
- 夜间增强：开启
- 黑白增强：开启
- 手电补光：关闭

## 使用

旧手机安装后，点击 START CAMERA SERVER。

另一台手机同 Wi-Fi 打开：

实时：
`http://摄像头手机IP:8080/?pin=123456`

远程设置：
`http://摄像头手机IP:8080/settings?pin=123456`

回放：
`http://摄像头手机IP:8080/recordings?pin=123456`

## 打包

新建 GitHub 仓库，上传解压后的内容。
如果 `.github` 文件夹没有上传成功，手动创建：

`.github/workflows/build-apk.yml`

内容复制根目录的 `build-apk.yml`。

然后进入 Actions 运行 `Build SafeCam Final APK`。

## 说明

这个稳定版不加入容易出错的实验广角接口。
摄像头不够广角时，建议手机放远一点，或加外接手机广角夹镜。
24fps 录像需要下一版改成 MP4/H.264 分段录像，当前版是图片循环记录。
